## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/<feature-slug>/` (`spec.md`, `issues/NN-<slug>.md`, `map.md`). See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, each label string equal to its role name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
